# astrbot_plugin_cmd_alias 指令替换
AstrBot 指令别名&正则替换插件，适配 AstrBot v4.29.4(不懂代码纯ai)

## ✨ 功能介绍
1. 支持普通文本别名替换 + 正则表达式替换
2. 规则写在配置文本框，一行一条，格式：`输入=输出`
3. 支持捕获组 `\1 \2` 引用，实现重排、提取内容
4. 优先级：99

## 📝 规则写法
- 普通匹配：`aa=bb`
- 正则匹配（前缀 `re:`）：`re:^[aa][bb](.*)$=ab\1`
- 自动忽略空行

> ⚠️ 正则默认是 `re.search` 模式，可匹配任意位置；加 `^` 代表强制开头匹配
